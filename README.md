# Realistic 3D Photo Album (写实三维拟真交互相册)

基于 Three.js + GSAP + TypeScript + Vite 构建的拟真 3D 交互翻页相册。

## 特性

- 📖 **拟真 3D 翻页交互**：支持手势/鼠标按住书页拖拽翻页，封面与封底平滑开合
- 🎥 **全景视角控制**：空白区域支持 360° 自由旋转视角与缩放
- ⚡ **现代化技术栈**：Three.js + GSAP 补间动画 + TypeScript + Vite 高性能渲染

## 快速开始

```bash
# 安装依赖
npm install

# 启动本地开发服务
npm run dev

# 构建生产版本
npm run build
```
